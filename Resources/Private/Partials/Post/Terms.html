Renders the categories and tags of a post. With settings.filterLinks enabled every term links to the list plugin (settings.filterLinks.pageUid, default: the current page) and filters it with the demand argument of the plugin namespace settings.filterLinks.namespace; the list plugin has to allow demand overwrites for that. Variables: post (Page), settings (plugin settings), contentElementData (plugin record, optional) or data (page record of a FLUIDTEMPLATE, optional) for the current page uid.
