Golb - Blog The Page Way

----

Golb turns regular TYPO3 pages into blog posts. A blog post is a page of
the "Blog post" page type: it is edited like any other page, uses the
page tree for structure, backend layouts and content elements for its
content, and system categories, tags and a publish date for its
metadata. Two frontend plugins list the posts.
